فایل را استخراج کنید و در پوشه‌ای که index.html دارد این دستور را با پایتون ۳ اجرا کنید:

python -m http.server 8000

در مرورگر همین کامپیوتر باز کنید:
http://localhost:8000

برای انتشار، فایل‌های همین پوشه را روی میزبان استاتیک HTTPS قرار دهید.
دریافت نقشه و مسیر به اینترنت نیاز دارد. برای موقعیت‌یابی روی گوشی از HTTPS استفاده کنید.
